# 📚 BookNook – A Small Online Library

**BookNook** is an online library management platform where users can explore books, add their own books, borrow books, and manage their borrowing activities. It provides a simple and user-friendly experience for book lovers.

🌐 **Live Website:** https://booknook-client-phi.vercel.app

## ✨ Features

- **User Authentication:** Secure registration and login with email and social authentication.
- **Browse Books:** Explore the available book collection and view detailed information about each book.
- **Add Books:** Authenticated users can add new books to the library.
- **Manage Books:** Users can edit and delete the books they have added.
- **Borrow Books:** Borrow available books and keep track of borrowing information.
- **Return Books:** Return borrowed books and update book availability.
- **My Books:** View and manage your own added books.
- **My Borrows:** View your borrowed books and monitor their return status.
- **User Profile:** View and manage your profile information.
- **Responsive Design:** Enjoy a smooth experience on desktop, tablet, and mobile devices.
- **Toast Notifications:** Get feedback for important actions such as adding, editing, borrowing, and returning books.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Sadia-IoT/booknook-client.git
```

### 2. Navigate to the project folder

```bash
cd booknook-client
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the root directory and add the required environment variables

### 5. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
